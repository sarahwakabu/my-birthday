# Sarah's Interactive Birthday Digital Notebook 🎂💕

A single-page interactive birthday website designed for a long-distance relationship, styled cleanly like a digital notebook on a soft paper-texture background.

## 🌟 Features
- **Landing Screen**: Animated cat SVG graphic, blowable birthday cake candle widget, "YES PLEASE" & playful evasive "NO THANKS" button.
- **Main Menu Hub ("THESE ARE FOR YOU!")**: Lined notebook aesthetic with Web Audio Lofi ambient background music player toggle.
- **29 Real Polaroid Memories Gallery**: Fullscreen Lightbox gallery with previous/next navigation and custom photo upload options.
- **Handwritten Love Letter**: Notebook UI with typewriter re-play mode and custom message editing.
- **Virtual Flower Bouquet**: Interactive blooming SVG bouquet with pop-up love compliment bubbles.
- **Secret Birthday Lock**: Unlocks "Our Future Plans" with a live reunion countdown timer and interactive milestone cards.

## 🚀 Usage
Open `index.html` directly in any browser! Zero build setup required.
